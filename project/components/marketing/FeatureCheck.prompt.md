The poster's orange check-mark + benefit line. Stack 3–5 in a "why us" / features list.

```jsx
<FeatureCheck>7 хоногт 4–5 удаагийн бэлтгэл</FeatureCheck>
<FeatureCheck>Хоолны дэглэм • Cardio • Fitness</FeatureCheck>
<FeatureCheck variant="circle">Хувийн дасгалжуулагч</FeatureCheck>
```

- `variant`: `box` rounded square (default, matches posters) · `circle` disc.
- Keep each line to one benefit; short, punchy, no period.
