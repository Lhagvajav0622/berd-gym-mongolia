The signature element — an oversized molten-orange price set like one of the brand's poster headlines. Use `mega` for the hero, `lg` inside membership cards.

```jsx
<PriceBlock amount="160K" unit="/ 3 сар" size="mega" />
<PriceBlock amount="250K" oldAmount="300K" unit="/ сар" />
```

- `amount` is a preformatted string ("250K", "250,000₮") — you control formatting.
- `oldAmount` adds a red strike-through above for discount pricing.
- Always the loudest thing on the screen — give it room; don't compete with another orange element beside it.
